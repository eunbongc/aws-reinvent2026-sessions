# AWS re:Invent 2026 세션 목록

AWS re:Invent 2026(2026년 11월 30일 ~ 12월 4일, 라스베이거스)의 세션을 한 화면에서 보고 고르기 위한 간단한 도구입니다.

## 쓸 수 있는 것

- 세션 목록을 분류·요일·장소·참석여부로 **필터**해서 봅니다.
- 세션을 펼쳐 **설명과 한글 해석**을 봅니다.
- 로그인하면 세션마다 **우선순위(⭕)·참석여부·메모**를 표시해 둘 수 있습니다. (내 표시는 나에게만 보입니다.)

## 언제 유용한가

일정이 겹치는 세션이 많아 무엇을 들을지 고르기 번거로울 때, 후보를 한 화면에서 추려 두고 비교하는 데 씁니다.

출장·참관을 준비하는 주변 몇몇과 공유하려고 간단히 만들어 배포했습니다.
